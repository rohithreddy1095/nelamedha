# Farm photos

Put photos of the farm in this folder and they appear on https://nelamedha.in/gallery/ a few minutes later.

From a phone: open this folder on github.com, tap **Add file → Upload files**, choose the photos, then tap **Commit changes**.

To give a photo a date and a caption, name it like this before uploading:

    2025-06-14 mango flowers.jpg

Without a date in the name, the date the camera recorded is used. The gallery shows smaller copies with the location and camera details removed; the original you upload here stays as it is, so remove anything you do not want public before uploading.

To take a photo off the site, delete it from this folder.
