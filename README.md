# Nelamedha

The website for Nelamedha, a research farm in Suryapet, Telangana, working on food forests, building with earth, and farm automation. In English and Telugu.

Live at https://nelamedha.in

## Editing

The pages are written by `tools/build.py`, which holds all the text in both languages. Change the text there, then run:

```
python3 tools/build.py
```

Satellite pictures of the farm are in `assets/img/sat/` (Esri World Imagery Wayback, © GeoEye, Maxar and Vantor).
